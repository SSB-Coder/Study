# L02: Informed Heuristic Search & The A* Algorithm

## 1. Intuition & The "Grand Analogy"
Imagine hiking toward a towering mountain peak visible on the horizon. 
- A blind hiker (Uniform Cost Search) checks every ditch and gulley in expanding circular rings around their starting point, wasting hours walking away from the mountain.
- A greedy hiker blindly charges directly toward the peak, getting trapped at the bottom of a shear cliff face.
- An **A* Search** hiker consults a compass and a topographic map. They calculate the total projected trip effort by combining the actual miles walked so far ($g(n)$) with an optimistic straight-line estimate of the remaining distance to the summit ($h(n)$). By always exploring the path that minimizes $f(n) = g(n) + h(n)$, they navigate around cliffs without ever expanding useless detours.

---

## 2. Architectural & Mathematical Breakdown
A* maintains a priority queue of candidate search nodes ordered by estimated total cost:
$$f(n) = g(n) + h(n)$$
where:
- $g(n)$: Exact cumulative cost from the start node $s_0$ to node $n$.
- $h(n)$: Heuristic estimate of the cheapest cost from node $n$ to any goal state.

### Admissibility & Consistency of Heuristics
1. **Admissibility (Optimism):** A heuristic $h(n)$ is **admissible** if it never overestimates the true remaining cost to the goal:
   $$0 \le h(n) \le h^*(n) \quad \forall n$$
   where $h^*(n)$ is the true optimal cost from $n$ to the goal.
2. **Consistency (Monotonicity / Triangle Inequality):** For every node $n$ and every successor $n'$ generated by action $a$:
   $$h(n) \le c(n, a, n') + h(n')$$
   Consistency implies that $f(n)$ is monotonically non-decreasing along any path.

---

## 3. Hardcore Mathematical Derivations

### Proof of A* Optimality with Consistent Heuristic
Let $G_2$ be a suboptimal goal state ($g(G_2) > C^*$, where $C^*$ is optimal goal cost).
Since $G_2$ is a goal, $h(G_2) = 0$, so:
$$f(G_2) = g(G_2) + h(G_2) = g(G_2) > C^*$$
Let $n$ be an unexpanded node on the frontier that lies along an optimal path to true optimal goal $G^*$.
Because $h$ is admissible:
$$f(n) = g(n) + h(n) \le g(n) + h^*(n) = C^*$$
Therefore:
$$f(n) \le C^* < f(G_2)$$
Because A* always expands the node with the lowest $f$-value, node $n$ will strictly be selected from the frontier before $G_2$ can ever be popped. A* cannot terminate with a suboptimal goal state.

## 4. Step-by-Step Algorithmic Walkthrough
```
Algorithm: A* Graph Search
Inputs: Start state s_0, Goal test, Heuristic function h(s)
1. Initialize OpenSet as Min-PriorityQueue containing (f=h(s_0), g=0, s_0, path=[s_0])
2. Initialize g_score = { s_0: 0 }, ClosedSet = empty
3. While OpenSet is not empty:
     pop node with lowest f = g + h
     If IsGoal(s):
        return path, g
     Add s to ClosedSet
     For each neighbor s' with step cost c:
        tentative_g = g + c
        If tentative_g < g_score.get(s', infinity):
           g_score[s'] = tentative_g
           f_score = tentative_g + h(s')
           push (f_score, tentative_g, s', path + [s']) to OpenSet
4. Return Failure
```

---

## 5. Failure Modes & When It Breaks
1. **Inadmissible Heuristic Overestimation:** If $h(n) > h^*(n)$ for even a single node, A* can prune the true optimal route and return a suboptimal path.
2. **Memory Exhaustion:** Like BFS, A* stores all open frontier nodes in memory ($\mathcal{O}(b^d)$), which fails on massive graphs (resolved by Memory-Bounded A* / IDA*).

## 6. Where This Fits in Modern LLMs & Transformers
- **Guided Decoding in Reasoning Models:** A* search guides chain-of-thought exploration in mathematical theorem proving (e.g. Lean-STaR), using Value networks as heuristic $h(s)$ to guide search over thought tokens.
