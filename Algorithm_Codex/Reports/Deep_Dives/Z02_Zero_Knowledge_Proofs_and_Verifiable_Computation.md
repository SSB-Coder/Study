# Z02: Zero-Knowledge Proofs & Verifiable Computation

## 1. Mathematical Formulation & Architecture
Zero-knowledge proofs (ZKPs), introduced by Goldwasser, Micali, and Rackoff (1985), enable a Prover to convince a Verifier that an assertion is mathematically true without disclosing any secret witness.

### The Schnorr $\Sigma$-Protocol
Let $p$ and $q$ be primes such that $q \mid (p - 1)$. Let $G_q \subset \mathbb{Z}_p^*$ be the unique cyclic subgroup of prime order $q$ generated by $g$.
The relation is knowledge of the discrete logarithm $x \in \mathbb{Z}_q$ satisfying public key $y = g^x \pmod p$.

The 3-move interactive $\Sigma$-protocol:
1. **Commitment**: Prover chooses ephemeral uniform nonce $r \xleftarrow{\$} \mathbb{Z}_q$, sends $t = g^r \pmod p$.
2. **Challenge**: Verifier sends random scalar $c \xleftarrow{\$} \mathbb{Z}_q$.
3. **Response**: Prover sends $s = (r + c \cdot x) \pmod q$.
4. **Verification**: Verifier confirms:
   $$g^s \equiv t \cdot y^c \pmod p$$

#### Fundamental Security Proofs:
1. **Completeness**: If Prover follows protocol:
   $$g^s = g^{r + cx} = g^r \cdot (g^x)^c \equiv t \cdot y^c \pmod p$$
2. **Special Soundness (Knowledge Extractor)**: Given two accepting transcripts $(t, c_1, s_1)$ and $(t, c_2, s_2)$ with the same commitment $t$ and $c_1 \ne c_2$:
   $$g^{s_1 - s_2} = y^{c_1 - c_2} \implies s_1 - s_2 \equiv (c_1 - c_2)x \pmod q$$
   The secret is efficiently extracted via modular inversion:
   $$x \equiv (s_1 - s_2)(c_1 - c_2)^{-1} \pmod q$$
3. **Honest-Verifier Zero-Knowledge (HVZK Simulator)**: A simulator choosing random $c, s \in \mathbb{Z}_q$ sets $t = g^s \cdot y^{-c} \pmod p$. The resulting distribution $(t, c, s)$ is computationally indistinguishable from real transcripts.
4. **Fiat-Shamir Heuristic (NIZK)**: Replacing $c$ with cryptographic hash $c = H(g, y, t, m)$ converts the protocol into a non-interactive signature of knowledge.

### Rank-1 Constraint Systems (R1CS)
General verifiable computation transforms arbitrary computer programs into arithmetic circuits over a finite field $\mathbb{F}_p$.
A program is compiled into a system of $m$ quadratic constraints across $n$ variables encoded as a witness vector $w = [1, \text{out}, x_1, \dots, x_k]^T \in \mathbb{F}_p^n$:
$$(A w) \circ (B w) \equiv (C w) \pmod p$$
where $A, B, C \in \mathbb{F}_p^{m \times n}$ and $\circ$ denotes the Hadamard (entrywise) product.

For example, computing polynomial $y = x^3 + x + 5 \pmod p$ decomposes into three elementary multiplication gates:
1. $x \cdot x = v_1$
2. $v_1 \cdot x = v_2$
3. $(v_2 + x + 5) \cdot 1 = y$

This R1CS form serves as the universal intermediate representation for modern zk-SNARKs (Groth16, PLONK, STARKs).

## 2. Implementation Details
The module `Z02_Zero_Knowledge_Proofs_and_Verifiable_Computation.py`:
- Implements `SchnorrZKP` with key generation, commitment, interactive and Fiat-Shamir challenges, verification, knowledge extraction, and HVZK transcript simulation.
- Implements `R1CSCircuit` with constraint matrix setup and witness vector validation over prime fields $\mathbb{F}_p$.
- Compiles the cubic arithmetic circuit and confirms that fraudulent computational claims are rejected.

## 3. Asymptotic & Numerical Analysis
- **Schnorr Protocol**: $\mathcal{O}(1)$ modular exponentiations. Communication is 2 group elements and 1 scalar ($\approx 96$ bytes in 256-bit elliptic curves).
- **R1CS Witness Verification**: $\mathcal{O}(m \cdot n)$ matrix-vector multiplications over $\mathbb{F}_p$, highly sparse in practice.

## 4. Edge Cases & Numerical Stability
- Nonce reuse ($r_1 = r_2$ across different challenges) instantly leaks the private key via the special soundness extractor (the classic catastrophic failure mode of Sony PS3 ECDSA).

## 5. Standalone Verification
The test suite validates:
- Interactive protocol completeness and rejection of tampered responses.
- Algebraic knowledge extraction recovering $x = 42$ from two challenges.
- HVZK simulator generating valid transcripts without knowledge of $x$.
- R1CS circuit correctly validating true cubic evaluation ($y = 35$) and rejecting false outputs ($y = 36$).
