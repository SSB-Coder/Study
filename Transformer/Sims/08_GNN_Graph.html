1. Intuition & Architectural Overview

Imagine a massive high school party. You want to figure out the "social status" (the features) of every single person there.

* **The Graph:** Everyone at the party is a "Node." The friendships between them are the "Edges." * **Message Passing:** At the start of the night, everyone only knows their own name and hobbies. Every hour, a bell rings. When the bell rings, everyone turns to all their immediate friends and tells them exactly who they are and what they know. * **Aggregation:** You listen to all your friends' gossip, combine it with what you already knew, and update your own "social status." * **Deep Learning:** When the bell rings a second time, you tell your friends the *new* combined gossip you learned. This means after two bells, you know information about your friends' friends.

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ h_v^{(k)} = \text{UPDATE}^{(k)} \left( h_v^{(k-1)}, \text{AGGREGATE}^{(k)} \left( \{ h_u^{(k-1)} : u \in \mathcal{N}(v) \} \right) \right) $$
EQUATION 2
$$ H^{(k)} = \sigma \left( \tilde{D}^{-\frac{1}{2}} \tilde{A} \tilde{D}^{-\frac{1}{2}} H^{(k-1)} W^{(k-1)} \right) $$

"""
08. Graph Neural Networks (GNN)
Deep Dive Implementation

This file explicitly demonstrates a Graph Convolutional Network (GCN) layer.
We manually define the Adjacency Matrix (A), the Degree Matrix (D), 
and perform the normalized Message Passing equation:
H_next = sigma( D^{-0.5} * A_tilde * D^{-0.5} * H_prev * W )
"""

import torch
import torch.nn as nn
import torch.nn.functional as F

class ExplicitGCNLayer(nn.Module):
    """A single layer of Graph Message Passing."""
    class="code-kw">def __init__(self, in_features, out_features):
        super().__init__()
        class="code-cmt"># The actual Neural Network part (W)
        self.weight = nn.Parameter(torch.FloatTensor(in_features, out_features))
        class="code-cmt"># Initialize weights
        nn.init.xavier_uniform_(self.weight)

    class="code-kw">def forward(self, H_prev, A_normalized):
        """
        H_prev: The feature matrix of all nodes [Num_Nodes, In_Features]
        A_normalized: The mathematically normalized Adjacency Matrix D^{-0.5} A_tilde D^{-0.5}
        """
        class="code-cmt"># Step 1: Feature Transformation (H * W)
        class="code-cmt"># Apply the neural network weights to every node's features
        support = torch.mm(H_prev, self.weight)
        
        class="code-cmt"># Step 2: Message Passing / Aggregation (A_norm * Support)
        class="code-cmt"># Matrix multiplication with the adjacency matrix inherently sums up the features 
        class="code-cmt"># of all neighboring nodes!
        output = torch.mm(A_normalized, support)
        
        return output

class="code-kw">def calculate_normalized_adjacency(A):
    """
    Calculates D^{-0.5} A_tilde D^{-0.5}
    """
    num_nodes = A.size(0)
    
    class="code-cmt"># 1. Add Self-Loops (A_tilde = A + I)
    class="code-cmt"># This ensures a node doesn't forget its own features when aggregating from friends
    I = torch.eye(num_nodes)
    A_tilde = A + I
    
    class="code-cmt"># 2. Calculate Degree Matrix (D)
    class="code-cmt"># Sum across the rows to see how many edges each node has
    degrees = A_tilde.sum(dim=1)
    
    class="code-cmt"># 3. Calculate D^{-0.5}
    class="code-cmt"># We raise degrees to -0.5. We use clamp to avoid division by zero.
    D_inv_sqrt = torch.pow(degrees.clamp(min=1e-12), -0.5)
    
    class="code-cmt"># Create a diagonal matrix out of the D_inv_sqrt vector
    D_inv_sqrt_diag = torch.diag(D_inv_sqrt)
    
    class="code-cmt"># 4. Final Matrix Multiplication
    class="code-cmt"># norm_A = D^{-0.5} @ A_tilde @ D^{-0.5}
    norm_A = torch.mm(torch.mm(D_inv_sqrt_diag, A_tilde), D_inv_sqrt_diag)
    
    return norm_A


class DeepGCN(nn.Module):
    """A 2-Layer GCN."""
    class="code-kw">def __init__(self, num_node_features, hidden_dim, num_classes):
        super().__init__()
        self.gc1 = ExplicitGCNLayer(num_node_features, hidden_dim)
        self.gc2 = ExplicitGCNLayer(hidden_dim, num_classes)

    class="code-kw">def forward(self, x, A_norm):
        class="code-cmt"># Layer 1 Message Passing
        x = self.gc1(x, A_norm)
        x = F.relu(x)
        
        class="code-cmt"># Layer 2 Message Passing
        x = self.gc2(x, A_norm)
        
        class="code-cmt"># Final Softmax to classify the nodes
        return F.log_softmax(x, dim=1)
