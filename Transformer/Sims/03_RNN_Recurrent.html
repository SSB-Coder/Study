1. Intuition & Architectural Overview

Imagine trying to understand the sentence: *"I grew up in France... so I speak fluent ____"*.

If you used a standard neural network (MLP), it would look at the word "fluent" completely in isolation. It has no memory. It wouldn't know what language to guess.

2. Core Architectural Components

  • The Current Word = **The Input ($X_t$)**
  • Your Short-Term Memory = **The Hidden State ($h_t$)**
  • The process of carrying the memory to the next word = **The Recurrent Loop**
  • If the weights in $W_{hh}$ are slightly greater than 1, multiplying them 50 times causes the gradient to explode to infinity (Exploding Gradient $\rightarrow$ NaN errors).

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ h_t = \tanh(W_{hh} h_{t-1} + W_{hx} x_t + b_h) $$
EQUATION 2
$$ \hat{y}_t = \text{softmax}(W_{yh} h_t + b_y) $$
EQUATION 3
$$ \frac{\partial \mathcal{L}_t}{\partial W_{hh}} = \sum_{k=1}^{t} \frac{\partial \mathcal{L}_t}{\partial \hat{y}_t} \frac{\partial \hat{y}_t}{\partial h_t} \left( \prod_{j=k+1}^{t} \frac{\partial h_j}{\partial h_{j-1}} \right) \frac{\partial h_k}{\partial W_{hh}} $$

"""
03. Recurrent Neural Networks (RNN)
Deep Dive Implementation

This file demonstrates the explicit inner workings of an RNN cell.
Instead of using `nn.RNN`, we manually define the W_hx and W_hh matrices 
and manually loop over the sequence length to show how the hidden state 
(the short-term memory) is passed forward through time.
"""

import torch
import torch.nn as nn

class ExplicitRNNCell(nn.Module):
    """A single unrolled time step of an RNN."""
    class="code-kw">def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        
        class="code-cmt"># W_hx: Weights for the incoming input x_t
        self.weight_ih = nn.Linear(input_size, hidden_size)
        
        class="code-cmt"># W_hh: Weights for the previous memory state h_{t-1}
        self.weight_hh = nn.Linear(hidden_size, hidden_size)
        
    class="code-kw">def forward(self, x_t, h_prev):
        class="code-cmt"># Equation: h_t = tanh(W_hx @ x_t + W_hh @ h_prev + bias)
        class="code-cmt"># Note: nn.Linear automatically handles the biases
        h_next = torch.tanh(self.weight_ih(x_t) + self.weight_hh(h_prev))
        return h_next

class ExplicitRNN(nn.Module):
    """The full RNN that unrolls the cell over the time sequence."""
    class="code-kw">def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.hidden_size = hidden_size
        self.rnn_cell = ExplicitRNNCell(input_size, hidden_size)
        
        class="code-cmt"># W_yh: Weights to map the hidden state to a final prediction
        self.fc_out = nn.Linear(hidden_size, output_size)
        
    class="code-kw">def forward(self, X_sequence):
        class="code-cmt"># X_sequence shape: [Batch, Sequence_Length, Input_Size]
        batch_size = X_sequence.size(0)
        seq_length = X_sequence.size(1)
        
        class="code-cmt"># Initialize the first hidden state (h_0) as all zeros (an empty memory)
        h_t = torch.zeros(batch_size, self.hidden_size, device=X_sequence.device)
        
        class="code-cmt"># We will collect the outputs at every time step just in case we need them
        outputs = []
        
        class="code-cmt"># The Unrolled Loop: Process the sequence one word/step at a time
        for t in range(seq_length):
            x_t = X_sequence[:, t, :] class="code-cmt"># Get the data at time t for all batches
            
            class="code-cmt"># Pass input and previous memory into the cell to get new memory
            h_t = self.rnn_cell(x_t, h_t)
            
            outputs.append(h_t)
            
        class="code-cmt"># We usually only care about the final prediction after reading the whole sequence
        final_memory = h_t
        
        class="code-cmt"># Make a prediction based on the final memory state
        logits = self.fc_out(final_memory)
        return logits
