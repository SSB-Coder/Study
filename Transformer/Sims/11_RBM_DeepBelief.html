1. Intuition & Architectural Overview

Imagine a room full of people. Some people are friends, some are enemies. * If two friends are standing next to each other, the room feels calm and relaxed. * If two enemies are standing next to each other, there is tension in the room.

We can assign a "Tension Score" (or "Energy") to the room. The room naturally wants to settle into the lowest possible energy state, where friends are together and enemies are apart.

2. Core Architectural Components

  • If two friends are standing next to each other, the room feels calm and relaxed.
  • If two enemies are standing next to each other, there is tension in the room.
  • $v_i$: The state (0 or 1) of visible node $i$.
  • $h_j$: The state (0 or 1) of hidden node $j$.

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ E(v, h) = - \sum_{i} a_i v_i - \sum_{j} b_j h_j - \sum_{i,j} v_i W_{ij} h_j $$
EQUATION 2
$$ P(v, h) = \frac{1}{Z} e^{-E(v, h)} $$
EQUATION 3
$$ Z = \sum_{v, h} e^{-E(v, h)} $$
EQUATION 4
$$ \Delta W_{ij} = \eta \left( \langle v_i h_j \rangle_{data} - \langle v_i h_j \rangle_{reconstruction} \right) $$

"""
11. Restricted Boltzmann Machines (RBM)
Deep Dive Implementation

This file explicitly demonstrates an RBM and the Contrastive Divergence (CD-1)
algorithm used to train it without standard backpropagation.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F

class RBM(nn.Module):
    """Restricted Boltzmann Machine."""
    class="code-kw">def __init__(self, visible_nodes, hidden_nodes):
        super().__init__()
        class="code-cmt"># W: Weight matrix between Visible and Hidden (Size: [Hidden, Visible])
        self.W = nn.Parameter(torch.randn(hidden_nodes, visible_nodes) * 0.1)
        
        class="code-cmt"># Biases
        self.h_bias = nn.Parameter(torch.zeros(hidden_nodes))
        self.v_bias = nn.Parameter(torch.zeros(visible_nodes))

    class="code-kw">def sample_hidden(self, v_prob):
        """
        Push data UP: Calculate P(h=1 | v) and sample a binary hidden state.
        Equation: P(h=1|v) = Sigmoid(v @ W^T + h_bias)
        """
        hidden_activation = F.linear(v_prob, self.W, self.h_bias)
        p_h_given_v = torch.sigmoid(hidden_activation)
        
        class="code-cmt"># Sample a hard binary 0 or 1 based on the probabilities
        class="code-cmt"># (Using torch.bernoulli for statistical sampling)
        h_sample = torch.bernoulli(p_h_given_v)
        return p_h_given_v, h_sample

    class="code-kw">def sample_visible(self, h_prob):
        """
        Push data DOWN: Calculate P(v=1 | h) and sample a reconstructed visible state.
        Equation: P(v=1|h) = Sigmoid(h @ W + v_bias)
        """
        class="code-cmt"># Note: self.W.t() flips the matrix to push backwards from hidden to visible
        visible_activation = F.linear(h_prob, self.W.t(), self.v_bias)
        p_v_given_h = torch.sigmoid(visible_activation)
        
        v_sample = torch.bernoulli(p_v_given_h)
        return p_v_given_h, v_sample

    class="code-kw">def forward(self, v_input):
        """
        The Forward pass is technically the Contrastive Divergence (CD-1) step.
        """
        class="code-cmt"># --- Positive Phase ---
        class="code-cmt"># Look at the real data and sample the hidden state
        p_h_real, h_real_sample = self.sample_hidden(v_input)
        
        class="code-cmt"># --- Negative Phase (The Reconstruction) ---
        class="code-cmt"># Take the sampled hidden state, and generate a 'fake' visible image
        p_v_fake, v_fake_sample = self.sample_visible(h_real_sample)
        
        class="code-cmt"># Take the fake image, and push it UP to the hidden state again
        p_h_fake, h_fake_sample = self.sample_hidden(p_v_fake)
        
        return v_input, p_h_real, p_v_fake, p_h_fake

    class="code-kw">def contrastive_divergence_loss(self, v_real, p_h_real, v_fake, p_h_fake):
        """
        Calculates the gradients based on the correlations of the Real state vs the Fake state.
        Delta_W = <v_i * h_j>_data - <v_i * h_j>_reconstruction
        (Note: We return this as a negative &class="code-cmt">#x27;loss' so PyTorch's standard optimizer can minimize it).
        """
        class="code-cmt"># Positive association (Real Data)
        positive_assoc = torch.matmul(p_h_real.t(), v_real)
        
        class="code-cmt"># Negative association (Fake Data)
        negative_assoc = torch.matmul(p_h_fake.t(), v_fake)
        
        class="code-cmt"># The gradient for W is actually (positive_assoc - negative_assoc) / batch_size
        class="code-cmt"># To use PyTorch's auto-optimizer (which minimizes loss), we construct a dummy loss
        class="code-cmt"># whose derivative wrt W equals our desired gradient.
        
        class="code-cmt"># We manually compute the update rule instead of relying on autograd for education:
        batch_size = v_real.size(0)
        grad_W = (positive_assoc - negative_assoc) / batch_size
        
        return grad_W

if __name__ == "__main__":

    class="code-cmt"># Calculate explicit gradient
    grad_W = rbm.contrastive_divergence_loss(v_real, p_h_real, p_v_fake, p_h_fake)
