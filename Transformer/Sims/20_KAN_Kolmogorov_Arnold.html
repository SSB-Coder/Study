1. Intuition & Architectural Overview

In April 2024, researchers from MIT and Caltech proposed **KAN**, a radical departure from this 60-year-old paradigm. Based on the Kolmogorov-Arnold representation theorem, KANs *remove* the static weights entirely.

Instead, **every single edge in a KAN is a learnable, non-linear mathematical function** (specifically, a B-spline). The nodes simply sum the results.

2. Core Architectural Components

  • Layer Transformations: Parameterized affine mapping and dimensional reshaping
  • Non-Linear Activation: Enforces non-linear feature separation across manifold
  • Residual Optimization: Direct gradient flow preserving signal fidelity

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

"""
20. Kolmogorov-Arnold Networks (KAN)
Deep Dive Implementation

This file explicitly demonstrates the difference between an MLP and a KAN.
Instead of `Weight Matrix * Input + Bias`, the KAN layer applies a learnable 
mathematical function (we approximate B-splines using radial basis functions for simplicity)
directly on the edges.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F

class SimplifiedKANLayer(nn.Module):
    """
    A simplified KAN layer.
    Instead of full B-splines (which require complex piecewise polynomial math),
    we use a sum of Gaussian Radial Basis Functions (RBFs) to approximate
    learnable, smooth, non-linear curves on the edges.
    """
    class="code-kw">def __init__(self, in_features, out_features, grid_size=5):
        super().__init__()
        self.in_features = in_features
        self.out_features = out_features
        self.grid_size = grid_size
        
        class="code-cmt"># In a KAN, we don't have a single weight W.
        class="code-cmt"># We have a set of coefficients for our curves on EVERY edge.
        class="code-cmt"># Total curves = in_features * out_features.
        class="code-cmt"># Each curve needs `grid_size` control points.
        self.curve_coefficients = nn.Parameter(
            torch.randn(out_features, in_features, grid_size) / grid_size
        )
        
        class="code-cmt"># The grid centers for our Gaussian bumps
        class="code-cmt"># We spread them evenly between -1 and 1
        self.grid = nn.Parameter(
            torch.linspace(-1, 1, grid_size), requires_grad=False
        )
        
        class="code-cmt"># A standard bias term on the output node
        self.bias = nn.Parameter(torch.zeros(out_features))

    class="code-kw">def forward(self, x):
        """
        x shape: [Batch, In_Features]
        """
        batch_size = x.size(0)
        
        class="code-cmt"># 1. Expand input to interact with our grid
        class="code-cmt"># x_expanded: [Batch, In_Features, 1]
        x_expanded = x.unsqueeze(-1)
        
        class="code-cmt"># 2. Calculate the Basis Functions (Gaussian bumps)
        class="code-cmt"># For every input value, how close is it to our grid centers?
        class="code-cmt"># basis: [Batch, In_Features, Grid_Size]
        sigma = 2.0 / self.grid_size class="code-cmt"># Width of the bump
        basis = torch.exp(-((x_expanded - self.grid) ** 2) / (sigma ** 2))
        
        class="code-cmt"># 3. Apply the learnable coefficients to warp the curves
        class="code-cmt"># This is where the "edge activation" happens!
        class="code-cmt"># We multiply the basis functions by our learnable curve coefficients.
        class="code-cmt"># We use einsum to do this efficiently across all in/out combinations.
        class="code-cmt"># Output is the value from evaluating the specific mathematical curve for each edge.
        class="code-cmt"># shape: [Batch, Out_Features, In_Features]
        edge_activations = torch.einsum(&class="code-cmt">#x27;big,oig->boi', basis, self.curve_coefficients)
        
        class="code-cmt"># 4. Sum up the edges at the output nodes
        class="code-cmt"># The node itself does NO activation function. It just sums.
        class="code-cmt"># shape: [Batch, Out_Features]
        node_sums = torch.sum(edge_activations, dim=-1) + self.bias
        
        return node_sums

class DeepKAN(nn.Module):
    class="code-kw">def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        class="code-cmt"># Note: No nn.ReLU() or nn.Sigmoid() between layers!
        class="code-cmt"># The non-linearity is already handled by the splines inside the KAN Layer.
        self.layer1 = SimplifiedKANLayer(input_dim, hidden_dim)
        self.layer2 = SimplifiedKANLayer(hidden_dim, output_dim)

    class="code-kw">def forward(self, x):
        x = self.layer1(x)
        x = self.layer2(x)
        return x
