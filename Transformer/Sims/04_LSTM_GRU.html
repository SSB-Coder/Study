1. Intuition & Architectural Overview

A standard RNN forgets things quickly (the vanishing gradient problem). Imagine someone reading a novel but they suffer from severe short-term memory loss; by chapter 5, they've forgotten the main character's name from chapter 1.

An **LSTM** fixes this by introducing a **Conveyor Belt** (the Cell State) that runs straight through the entire network from start to finish. Information can flow down this conveyor belt unchanged, preserving memories over huge distances.

2. Core Architectural Components

  • If the gate outputs `0`, it means "completely block this / forget this".
  • If the gate outputs `1`, it means "let this entirely through / remember this".
  • **The Simplification:** It merges the Cell State and Hidden State into a single vector. It also merges the Forget and Input gates into a single "Update Gate."

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) $$
EQUATION 2
$$ i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) $$
EQUATION 3
$$ \tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C) $$
EQUATION 4
$$ C_t = f_t * C_{t-1} + i_t * \tilde{C}_t $$

import torch
import torch.nn as nn

class ExplicitLSTMCell(nn.Module):
    """A single time step of an LSTM, showing the conveyor belt logic."""
    class="code-kw">def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        
        class="code-cmt"># In PyTorch, we can combine the inputs x_t and h_{t-1} into one vector.
        class="code-cmt"># So we need a Linear layer that takes (input_size + hidden_size)
        combined_size = input_size + hidden_size
        
        class="code-cmt"># 1. The Forget Bouncer (f_t)
        self.W_f = nn.Linear(combined_size, hidden_size)
        
        class="code-cmt"># 2. The Input Bouncer (i_t) and Candidate Value (C_tilde)
        self.W_i = nn.Linear(combined_size, hidden_size)
        self.W_C = nn.Linear(combined_size, hidden_size)
        
        class="code-cmt"># 3. The Output Bouncer (o_t)
        self.W_o = nn.Linear(combined_size, hidden_size)

    class="code-kw">def forward(self, x_t, h_prev, c_prev):
        class="code-cmt"># Concatenate input and previous hidden state: [x_t, h_{t-1}]
        combined = torch.cat((x_t, h_prev), dim=1)
        
        class="code-cmt"># Step 1: Forget Gate - What old memory should we erase?
        f_t = torch.sigmoid(self.W_f(combined))
        
        class="code-cmt"># Step 2: Input Gate - What new memory should we keep?
        i_t = torch.sigmoid(self.W_i(combined))
        C_tilde = torch.tanh(self.W_C(combined)) class="code-cmt"># The proposed new candidate memory
        
        class="code-cmt"># Step 3: Update the Conveyor Belt (Cell State)
        class="code-cmt"># Multiply old memory by forget gate, add new memory scaled by input gate
        c_next = (f_t * c_prev) + (i_t * C_tilde)
        
        class="code-cmt"># Step 4: Output Gate - What part of the conveyor belt do we output?
        o_t = torch.sigmoid(self.W_o(combined))
        h_next = o_t * torch.tanh(c_next)
        
        return h_next, c_next


class ExplicitGRUCell(nn.Module):
    """A single time step of a GRU, showing the simplified gate logic."""
    class="code-kw">def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        combined_size = input_size + hidden_size
        
        class="code-cmt"># 1. Update Gate (z_t) - Blends Forget and Input gates
        self.W_z = nn.Linear(combined_size, hidden_size)
        
        class="code-cmt"># 2. Reset Gate (r_t) - Decides what past to ignore entirely
        self.W_r = nn.Linear(combined_size, hidden_size)
        
        class="code-cmt"># 3. Candidate Hidden State computation
        class="code-cmt"># Note: the candidate takes input and the *reset* hidden state
        self.W_h = nn.Linear(combined_size, hidden_size)

    class="code-kw">def forward(self, x_t, h_prev):
        combined = torch.cat((x_t, h_prev), dim=1)
        
        z_t = torch.sigmoid(self.W_z(combined))
        r_t = torch.sigmoid(self.W_r(combined))
        
        class="code-cmt"># Calculate the candidate state using the reset memory
        combined_reset = torch.cat((x_t, r_t * h_prev), dim=1)
        h_tilde = torch.tanh(self.W_h(combined_reset))
        
        class="code-cmt"># Final Memory Update: Blend old memory and candidate memory based on z_t
        h_next = (1 - z_t) * h_prev + z_t * h_tilde
        
        return h_next
