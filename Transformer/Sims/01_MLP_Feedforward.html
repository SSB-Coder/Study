1. Intuition & Architectural Overview

Imagine a factory assembly line trying to figure out if a picture shows a "Cat" or a "Dog." * **The Input (The Raw Materials):** The picture is broken down into tiny pixels, and each pixel is handed to a worker at the start of the line. * **The Hidden Layers (The Specialists):** These first workers don't know what a cat is. They just look at their pixel and shout a number indicating how bright it is. The next line of workers listens to the shouts. One worker in the second row is trained to only listen to workers holding pixels that form a *curve* (like an ear). Another listens for *straight lines* (like a whisker). They add up the shouts they hear. If the shouts are loud enough, they pass the message to the next row. * **The Output (The Final Vote):** By the end of the factory, the final workers are listening to high-level specialists (e.g., "I saw two pointy ears!" and "I saw whiskers!"). They tally the final votes and declare: "It's a Cat!"

An MLP is exactly this: an assembly line of mathematical workers (neurons) passing signals strictly forward, making increasingly complex decisions at each step.

  • **Input Layer:** A vector of raw numbers (e.g., flattened image pixels). No computation happens here.

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]} $$
EQUATION 2
$$ A^{[l]} = g^{[l]}(Z^{[l]}) $$
EQUATION 3
$$ \mathcal{J}(W, b) = - \frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(a^{[L](i)}) + (1 - y^{(i)}) \log(1 - a^{[L](i)}) \right] $$
EQUATION 4
$$ dZ^{[L]} = A^{[L]} - Y $$

"""
01. Multi-Layer Perceptron (MLP) & Feedforward Neural Network
Deep Dive Implementation

This file explicitly demonstrates the forward pass and mathematics of an MLP.
Instead of just using `nn.Linear`, we implement the explicit matrix multiplication
y = x @ W^T + b to match the mathematical equations in the report.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F

class ExplicitLinearLayer(nn.Module):
    """An explicit mathematical representation of a single Dense layer."""
    class="code-kw">def __init__(self, in_features, out_features):
        super().__init__()
        class="code-cmt"># Initialize Weights (W) and Biases (b) explicitly
        class="code-cmt"># We use kaiming/he initialization scaled manually
        stdv = 1. / (in_features ** 0.5)
        self.weight = nn.Parameter(torch.empty(out_features, in_features).uniform_(-stdv, stdv))
        self.bias = nn.Parameter(torch.zeros(out_features))

    class="code-kw">def forward(self, x):
        class="code-cmt"># The core equation: Z = XW^T + b
        class="code-cmt"># F.linear(x, self.weight, self.bias) does exactly: x @ self.weight.T + self.bias
        class="code-cmt"># We write it out explicitly for educational purposes:
        return torch.matmul(x, self.weight.t()) + self.bias

class DeepMLP(nn.Module):
    """A deep feedforward network acting as our &class="code-cmt">#x27;Assembly Line'."""
    class="code-kw">def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        class="code-cmt"># Input Layer -> Hidden Layer 1
        self.layer1 = ExplicitLinearLayer(input_dim, hidden_dim)
        
        class="code-cmt"># Hidden Layer 1 -> Hidden Layer 2
        self.layer2 = ExplicitLinearLayer(hidden_dim, hidden_dim)
        
        class="code-cmt"># Hidden Layer 2 -> Output Layer
        self.layer3 = ExplicitLinearLayer(hidden_dim, output_dim)

    class="code-kw">def forward(self, x):
        class="code-cmt"># Forward pass tracking the activations (A)
        class="code-cmt"># Z^[1] = X @ W^[1]T + b^[1]
        z1 = self.layer1(x)
        class="code-cmt"># A^[1] = ReLU(Z^[1])
        a1 = F.relu(z1)
        
        class="code-cmt"># Z^[2] = A^[1] @ W^[2]T + b^[2]
        z2 = self.layer2(a1)
        class="code-cmt"># A^[2] = ReLU(Z^[2])
        a2 = F.relu(z2)
        
        class="code-cmt"># Z^[3] = A^[2] @ W^[3]T + b^[3]
        logits = self.layer3(a2)
        
        class="code-cmt"># Output is Raw Logits (We apply Sigmoid/Softmax in the loss function)
        return logits

if __name__ == "__main__":
    print("--- 01. MLP & Feedforward Network ---")
    class="code-cmt"># Simulate a batch of 8 images, each 28x28 pixels flattened (784)
    batch_size = 8
    input_features = 784 
    hidden_units = 128
    num_classes = 10 class="code-cmt"># E.g., classifying digits 0-9

    mlp = DeepMLP(input_features, hidden_units, num_classes)
    
    class="code-cmt"># Generate dummy data
    X_dummy = torch.randn(batch_size, input_features)

    predictions = mlp(X_dummy)

    print(f"Output Shape: {predictions.shape} [Batch Size, Classes]")

    probabilities = F.softmax(predictions, dim=1)
