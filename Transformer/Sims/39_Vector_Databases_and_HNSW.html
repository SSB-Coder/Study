1. Intuition & Architectural Overview

However, standard SQL databases (PostgreSQL, MySQL) search for *exact keyword matches*. If a user asks "How do I fix a flat tire?", and the company manual says "Instructions for mending a punctured wheel," an SQL database will return 0 results.

We must use **Vector Databases** (like Pinecone, FAISS, or Milvus), which search by *mathematical meaning*. * **See Code:** [39_Vector_Databases_and_HNSW.py](../Code/Deep_Dives/39_Vector_Databases_and_HNSW.py)

2. Core Architectural Components

  • **See Code:** [39_Vector_Databases_and_HNSW.py](../Code/Deep_Dives/39_Vector_Databases_and_HNSW.py)
  • **Layer 0 (The Base):** Contains every single document vector in the database. Each vector is connected to its closest neighbors (creating a "Small World" network).
  • **Layer 1:** Contains only 10% of the vectors.
  • **Layer 2:** Contains only 1% of the vectors.

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

class="code-kw">def cosine_similarity(vec_a, vec_b):
    """
    Calculates the angle between two high-dimensional vectors.
    1.0 means perfectly identical meaning. 
    0.0 means completely unrelated.
    -1.0 means opposite meaning.
    """
    dot_product = np.dot(vec_a, vec_b)
    norm_a = np.linalg.norm(vec_a)
    norm_b = np.linalg.norm(vec_b)
    
    if norm_a == 0 or norm_b == 0:
        return 0.0
        
    return dot_product / (norm_a * norm_b)

class="code-kw">def greedy_graph_search(entry_node, query_vector):
    """
    Simulates navigating the "Small World" graph.
    Instead of checking all 1 million nodes, we start at the entry node,
    and greedily walk towards neighbors that have higher cosine similarity
    to our query vector. We stop when no neighbors are closer.
    """
    current_node = entry_node
    current_similarity = cosine_similarity(query_vector, current_node.vector)
    
    path_taken = [current_node.id]
    
    while True:
        best_neighbor = None
        best_neighbor_sim = current_similarity
        
        class="code-cmt"># Look at all connected neighbors
        for neighbor in current_node.connections:
            sim = cosine_similarity(query_vector, neighbor.vector)
            if sim > best_neighbor_sim:
                best_neighbor = neighbor
                best_neighbor_sim = sim
                
        class="code-cmt"># If we found a neighbor that is closer to our query, walk to it
        if best_neighbor is not None:
            current_node = best_neighbor
            current_similarity = best_neighbor_sim
            path_taken.append(current_node.id)
        else:
            class="code-cmt"># We reached a local maximum (the closest node in this neighborhood)
            break
            
    return current_node, current_similarity, path_taken
