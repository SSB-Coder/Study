3. Advantages & Trade-Offs

In the `ppo_step` function, the math executes as follows: 1. **Advantages:** The code calculates `Advantage = (Actual Reward) - (Expected Value)`. If the advantage is positive, the model did better than expected. 2. **KL Divergence Penalty:** The code calculates `logprobs_new - logprobs_ref`. If the active model has changed its weights too drastically from the frozen reference model (e.g., trying to cheat the reward model by spamming the word "Please"), it gets penalized, dragging the Advantage down. 3. **Clipped Surrogate Objective:** To prevent the model from destroying its own weights in a single update, PPO uses `torch.clamp`. If the ratio of the new probability to the old probability exceeds `1.0 + clip_range` (usually 1.2), the gradient is capped. This ensures the model learns slowly and stably.

class="code-kw">def calculate_kl_divergence(logprobs_policy, logprobs_ref):
    """
    Calculates how far the active model has drifted from the reference model.
    We penalize the model if it changes its personality too much to cheat the reward model.
    """
    return logprobs_policy - logprobs_ref

class="code-kw">def ppo_step(
    prompts,               class="code-cmt"># The input context
    responses,             class="code-cmt"># The text generated by the model
    logprobs_old,          class="code-cmt"># Log probabilities from the model *before* the update
    logprobs_ref,          class="code-cmt"># Log probabilities from the frozen reference model
    rewards,               class="code-cmt"># Scalar score from the Reward Model
    values_old,            class="code-cmt"># Value predictions from the Value Model
    policy_model,          class="code-cmt"># The LLM we are training
    value_model,           class="code-cmt"># The model predicting expected rewards
    optimizer_policy,
    optimizer_value,
    clip_range=0.2,
    kl_beta=0.1
):
    """
    Executes a single step of Proximal Policy Optimization.
    """
    class="code-cmt"># 1. Forward Pass (Get current predictions)
    logits_new = policy_model(responses) 
    logprobs_new = F.log_softmax(logits_new, dim=-1).max(dim=-1).values class="code-cmt"># Simplified logprob selection
    values_new = value_model(responses)
    
    class="code-cmt"># 2. Calculate KL Penalty (Don't drift too far from reference!)
    kl_penalty = calculate_kl_divergence(logprobs_new, logprobs_ref)
    
    class="code-cmt"># 3. Calculate Advantages (Did this action result in a better reward than we expected?)
    class="code-cmt"># Advantage = (Actual Reward - KL Penalty) - Expected Value
    class="code-cmt"># (In reality, we use Generalized Advantage Estimation (GAE) across the sequence length)
    advantages = (rewards - kl_beta * kl_penalty) - values_old.detach()
    
    class="code-cmt"># Normalize advantages for training stability
    advantages = (advantages - advantages.mean()) / (advantages.std() + 1e-8)
    
    class="code-cmt"># 4. PPO Policy Loss (The clipped surrogate objective)
    class="code-cmt"># Ratio of new probability to old probability
    ratio = torch.exp(logprobs_new - logprobs_old)
    
    class="code-cmt"># Unclipped objective
    pg_loss1 = -advantages * ratio
    
    class="code-cmt"># Clipped objective (Prevent massive, unstable updates)
    pg_loss2 = -advantages * torch.clamp(ratio, 1.0 - clip_range, 1.0 + clip_range)
    
    class="code-cmt"># Final Policy Loss (Take the worst-case scenario)
    policy_loss = torch.max(pg_loss1, pg_loss2).mean()
    
    class="code-cmt"># 5. Value Model Loss (Train the value model to predict rewards better)
    class="code-cmt"># MSE between predicted values and actual received rewards
    returns = rewards - kl_beta * kl_penalty
    value_loss = F.mse_loss(values_new, returns.detach())
    
    class="code-cmt"># 6. Backpropagation
    optimizer_policy.zero_grad()
    policy_loss.backward(retain_graph=True)
    optimizer_policy.step()
    
    optimizer_value.zero_grad()
    value_loss.backward()
    optimizer_value.step()
    
    return policy_loss.item(), value_loss.item(), kl_penalty.mean().item()
