1. Intuition & Architectural Overview

This report covers the foundational theory, mathematics, and concepts behind how Artificial Intelligence (AI) models learn, from the atomic scale to basic neural networks.

* **Artificial Intelligence (AI):** The broad field of creating systems capable of performing tasks that typically require human intelligence. * **Machine Learning (ML):** A subset of AI that uses algorithms to parse data, learn from it, and make informed decisions. Instead of explicit programming, ML uses statistical methods to improve performance on a task over time. * **Deep Learning (DL):** A subset of ML based on Artificial Neural Networks (ANNs) with multiple layers (hence "deep"). DL models attempt to simulate the behavior of the human brain to learn from large amounts of data. * **Large Language Models (LLMs):** Massive DL models, typically based on the Transformer architecture, trained on vast amounts of text data to understand and generate human-like language.

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ z = \sum_{i=1}^{n} (w_i \cdot x_i) + b = W \cdot X + b $$
EQUATION 2
$$ a = f(z) $$
EQUATION 3
$$ Z^{[l]} = W^{[l]} \cdot A^{[l-1]} + b^{[l]} $$
EQUATION 4
$$ A^{[l]} = f^{[l]}(Z^{[l]}) $$

class Perceptron:
    """
    The simplest neural network model.
    Learns a linear decision boundary for binary classification.
    """
    class="code-kw">def __init__(self, learning_rate=0.01, n_iterations=1000):
        self.lr = learning_rate
        self.n_iters = n_iterations
        self.weights = None
        self.bias = None

    class="code-kw">def _activation_func(self, x):
        class="code-cmt"># Step function: 1 if x>=0 else 0
        return np.where(x >= 0, 1, 0)

    class="code-kw">def fit(self, X, y):
        n_samples, n_features = X.shape
        
        class="code-cmt"># Initialize parameters
        self.weights = np.zeros(n_features)
        self.bias = 0

        class="code-cmt"># Ensure y is binary (0 or 1)
        y_ = np.array([1 if i > 0 else 0 for i in y])

        for _ in range(self.n_iters):
            for idx, x_i in enumerate(X):
                class="code-cmt"># Forward pass: dot product of weights and input + bias
                linear_output = np.dot(x_i, self.weights) + self.bias
                y_predicted = self._activation_func(linear_output)

                class="code-cmt"># Update rule (Delta rule)
                update = self.lr * (y_[idx] - y_predicted)
                self.weights += update * x_i
                self.bias += update

    class="code-kw">def predict(self, X):
        linear_output = np.dot(X, self.weights) + self.bias
        return self._activation_func(linear_output)

class NeuralNetwork:
    """
    A simple 2-layer (1 hidden, 1 output) Feedforward Neural Network using pure NumPy.
    Uses Sigmoid activation and Mean Squared Error loss.
    """
    class="code-kw">def __init__(self, input_size, hidden_size, output_size, learning_rate=0.1):
        self.input_size = input_size
        self.hidden_size = hidden_size
        self.output_size = output_size
        self.lr = learning_rate

        class="code-cmt"># Initialize Weights randomly, Biases to zero
        class="code-cmt"># Shape: (input_size x hidden_size)
        self.W1 = np.random.randn(self.input_size, self.hidden_size) * 0.01
        self.b1 = np.zeros((1, self.hidden_size))
        
        class="code-cmt"># Shape: (hidden_size x output_size)
        self.W2 = np.random.randn(self.hidden_size, self.output_size) * 0.01
        self.b2 = np.zeros((1, self.output_size))

    class="code-cmt"># Activation Functions
    class="code-kw">def sigmoid(self, z):
        class="code-cmt"># Using np.clip to prevent overflow warnings in exp
        z = np.clip(z, -500, 500)
        return 1 / (1 + np.exp(-z))

    class="code-kw">def sigmoid_derivative(self, z):
        s = self.sigmoid(z)
        return s * (1 - s)

    class="code-kw">def forward(self, X):
        """
        Forward propagation: Data flows from input to output.
        """
        class="code-cmt"># Layer 1
        self.Z1 = np.dot(X, self.W1) + self.b1
        self.A1 = self.sigmoid(self.Z1)
        
        class="code-cmt"># Layer 2 (Output)
        self.Z2 = np.dot(self.A1, self.W2) + self.b2
        self.A2 = self.sigmoid(self.Z2)
        
        return self.A2

    class="code-kw">def backward(self, X, y, output):
        """
        Backpropagation: Calculate gradients and update weights.
        """
        m = X.shape[0] class="code-cmt"># Number of training examples
        
        class="code-cmt"># Ensure y is shaped correctly (m x 1)
        y = y.reshape(-1, 1)

        class="code-cmt"># 1. Compute Loss Gradient at output layer
        class="code-cmt"># Derivative of MSE is (output - y), multiplied by activation derivative
        dZ2 = (output - y) * self.sigmoid_derivative(self.Z2)
        dW2 = (1 / m) * np.dot(self.A1.T, dZ2)
        db2 = (1 / m) * np.sum(dZ2, axis=0, keepdims=True)

        class="code-cmt"># 2. Propagate error to hidden layer
        dZ1 = np.dot(dZ2, self.W2.T) * self.sigmoid_derivative(self.Z1)
        dW1 = (1 / m) * np.dot(X.T, dZ1)
        db1 = (1 / m) * np.sum(dZ1, axis=0, keepdims=True)

        class="code-cmt"># 3. Update Weights and Biases (Gradient Descent step)
        self.W1 -= self.lr * dW1
        self.b1 -= self.lr * db1
        self.W2 -= self.lr * dW2
        self.b2 -= self.lr * db2

    class="code-kw">def train(self, X, y, epochs):

            class="code-cmt"># Forward pass
            output = self.forward(X)
            
            class="code-cmt"># Backward pass
            self.backward(X, y, output)
