1. Intuition & Architectural Overview

This report explores the architecture that revolutionized AI: The Transformer. It breaks down the classic structures and dives deeply into the highly advanced, agentic systems defining the modern landscape: ChatGPT (GPT-4o & o1/o3), Claude (3.5 Sonnet & Opus), Gemini (1.5 & 2.0 Pro/Flash), and Open Source alternatives (Llama 3, DeepSeek-V3/R1).

Introduced in 2017, the Transformer solved the parallelization problem of RNNs by processing the entire sequence simultaneously.

2. Core Architectural Components

  • **Claude 3.5 Sonnet / Opus:** Industry standard in reasoning, multi-step tool use, and computer use.
  • **OpenAI o1 / o3:** Test-time compute scaling using reinforcement learning over chain-of-thought tokens.
  • **GPT-4o:** Unified natively omnimodal tokenization across text, audio, and vision.
  • **DeepSeek-V3 / R1:** Multi-Head Latent Attention (MLA) and pure RL reasoning emergence.

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

import torch
import torch.nn as nn
import math

class="code-cmt"># ==========================================
class="code-cmt"># CORE ATTENTION MECHANISM
class="code-cmt"># The engine behind all modern LLMs.
class="code-cmt"># ==========================================

class SelfAttention(nn.Module):
    """
    Scaled Dot-Product Self Attention from scratch.
    Equation: Attention(Q, K, V) = softmax(Q * K^T / sqrt(d_k)) * V
    """
    class="code-kw">def __init__(self, embed_size, heads):
        super(SelfAttention, self).__init__()
        self.embed_size = embed_size
        self.heads = heads
        
        class="code-cmt"># The dimension of each head
        self.head_dim = embed_size // heads
        
        assert (
            self.head_dim * heads == embed_size
        ), "Embedding size needs to be divisible by heads"

        class="code-cmt"># Explicitly defining the weight matrices for Query, Key, and Value
        class="code-cmt"># Instead of doing nn.Linear for each head, we do one massive nn.Linear
        class="code-cmt"># and reshape it later for efficiency.
        self.values = nn.Linear(embed_size, embed_size, bias=False)
        self.keys = nn.Linear(embed_size, embed_size, bias=False)
        self.queries = nn.Linear(embed_size, embed_size, bias=False)
        
        class="code-cmt"># Final linear layer to mix the heads back together
        self.fc_out = nn.Linear(embed_size, embed_size)

    class="code-kw">def forward(self, values, keys, queries, mask=None):
        N = queries.shape[0] class="code-cmt"># Batch size
        value_len, key_len, query_len = values.shape[1], keys.shape[1], queries.shape[1]

        class="code-cmt"># 1. Project the inputs through the weight matrices
        values = self.values(values)
        keys = self.keys(keys)
        queries = self.queries(queries)

        class="code-cmt"># 2. Reshape into Multiple Heads
        class="code-cmt"># Shape: (Batch_size, sequence_length, heads, head_dim)
        values = values.reshape(N, value_len, self.heads, self.head_dim)
        keys = keys.reshape(N, key_len, self.heads, self.head_dim)
        queries = queries.reshape(N, query_len, self.heads, self.head_dim)

        class="code-cmt"># 3. Calculate Dot Product of Queries and Keys
        class="code-cmt"># We use einsum for clarity in tensor multiplication.
        class="code-cmt"># "nqhd,nkhd->nhqk" means: 
        class="code-cmt">#   Multiply queries (q) and keys (k) along the 'd' (head_dim) dimension.
        class="code-cmt">#   Resulting shape: (Batch_size, heads, query_len, key_len)
        energy = torch.einsum("nqhd,nkhd->nhqk", [queries, keys])

        class="code-cmt"># 4. Scale and Mask
        if mask is not None:
            class="code-cmt"># If masking (e.g., in a decoder so it can't look at future words),
            class="code-cmt"># set the masked positions to -infinity so softmax makes them 0.
            energy = energy.masked_fill(mask == 0, float("-1e20"))

        class="code-cmt"># Scale by sqrt(d_k) to prevent gradients from vanishing/exploding
        attention = torch.softmax(energy / math.sqrt(self.head_dim), dim=3)

        class="code-cmt"># 5. Multiply by Values
        class="code-cmt"># "nhqk,nvhd->nqhd"
        class="code-cmt"># Resulting shape: (Batch_size, query_len, heads, head_dim)
        out = torch.einsum("nhqk,nvhd->nqhd", [attention, values])

        class="code-cmt"># 6. Concatenate heads back together
        class="code-cmt"># Shape becomes: (Batch_size, query_len, embed_size)
        out = out.reshape(N, query_len, self.embed_size)

        class="code-cmt"># 7. Final linear projection
        out = self.fc_out(out)
        
        return out


if __name__ == "__main__":
    print("Testing Multi-Head Self-Attention Component...")
    embed_size = 512
    heads = 8
    seq_length = 100
    batch_size = 4

    out = attention_layer(values=x, keys=x, queries=x, mask=None)
