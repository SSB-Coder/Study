1. Intuition & Architectural Overview

All the neural networks discussed so far (MLPs, CNNs, Transformers) use continuous decimal numbers. If a neuron sees a cat, it might shout the number "0.87".

But the actual biological human brain does not transmit decimal numbers. It transmits sharp electrical zaps called "Action Potentials" or "Spikes". It's either 1 (a zap) or 0 (silence).

2. Core Architectural Components

  • **Inputs:** Water is poured into the bucket in tiny cupfuls from other connected buckets.
  • **Leakage:** Because of the hole, if water isn't poured in fast enough, the bucket will slowly drain to empty.
  • **The Spike:** If you pour water in rapidly from multiple friends at the exact same time, the bucket fills to the top. The moment the water hits the brim (the Threshold), the bucket immediately dumps ALL its water onto the next bucket, and resets to completely empty.
  • $V_m(t)$: The current voltage of the neuron at time $t$ (how full the bucket is).

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

import torch
import torch.nn as nn

class SurrogateSpike(torch.autograd.Function):
    """
    The Surrogate Gradient Trick.
    Forward Pass: Returns a hard 1 or 0 (biological spike).
    Backward Pass: Pretends the spike was a smooth sigmoid curve so calculus works.
    """
    @staticmethod
    class="code-kw">def forward(ctx, voltage_membrane, threshold):
        class="code-cmt"># Save voltage for the backward pass
        ctx.save_for_backward(voltage_membrane, threshold)
        
        class="code-cmt"># Hard Spike: If voltage >= threshold, return 1.0, else 0.0
        return (voltage_membrane >= threshold).float()

    @staticmethod
    class="code-kw">def backward(ctx, grad_output):
        voltage_membrane, threshold = ctx.saved_tensors
        
        class="code-cmt"># We approximate the Dirac Delta derivative with a Fast Sigmoid derivative
        class="code-cmt"># The steepness of this curve is controlled by alpha
        alpha = 2.0
        surrogate_gradient = (1 / (alpha * torch.abs(voltage_membrane - threshold) + 1.0) ** 2)
        
        class="code-cmt"># Chain rule
        return grad_output * surrogate_gradient, None

class="code-cmt"># Wrap the autograd function so it acts like a normal PyTorch layer
spike_activation = SurrogateSpike.apply

        input_spikes: binary tensor of spikes from previous layer [Batch, In_Features]

        class="code-cmt"># We mathematically mask out the voltage of neurons that just fired
        voltage_next = voltage_next * (1.0 - out_spikes)
        
        return out_spikes, voltage_next
