1. Intuition & Architectural Overview

An NVIDIA H100 GPU has two main resources: 1. **FLOPs (Math Speed):** It can do ~2,000 Trillion floating-point operations per second. 2. **Memory Bandwidth (Data Speed):** It can move data from its main RAM (HBM) to its calculation cores at ~3.35 Terabytes per second.

---

2. Core Architectural Components

  • **CUDA (C++):** Extremely difficult. You must manually manage "Thread Blocks", "Warps", and bank conflicts in memory.
  • **Triton (Python):** Invented by OpenAI. It looks like Python, but it compiles down to native GPU machine code. It automatically handles memory coalescing and thread management.
  • **See Code:** [23_Triton_FlashAttention.py](../Code/Deep_Dives/23_Triton_FlashAttention.py)

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

    off_hz = tl.program_id(1)  class="code-cmt"># Which Batch/Head is this thread processing?

    qvk_offset = off_hz * stride_qh

    class="code-cmt"># tl.arange creates an array of offsets: [0, 1, 2... BLOCK_M - 1]
    offs_m = start_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = tl.arange(0, BLOCK_N)
    offs_d = tl.arange(0, BLOCK_DMODEL)

    k_ptrs = K + qvk_offset + offs_d[:, None] * stride_kk + offs_n[None, :] * stride_kn
    v_ptrs = V + qvk_offset + offs_n[:, None] * stride_vk + offs_d[None, :] * stride_vn

    class="code-cmt"># Load the block of Queries from slow HBM into fast SRAM
    q = tl.load(q_ptrs)
    
    class="code-cmt"># We iterate over the sequence length in chunks of BLOCK_N

        class="code-cmt"># 1. Load a block of Keys from HBM -> SRAM
        k = tl.load(k_ptrs)
        
        class="code-cmt"># 2. Compute Q * K^T (Matrix Multiplication in SRAM)
        qk = tl.dot(q, k)
        
        class="code-cmt"># 3. Apply scaling factor (1 / sqrt(d_model))
        qk = qk * 0.125 class="code-cmt"># Assuming d_model = 64, sqrt(64) = 8, 1/8 = 0.125

        class="code-cmt"># 5. Multiply Attention Scores by Values (acc = acc + qk * v)
        acc += tl.dot(qk, v)
        
        class="code-cmt"># Move pointers to the next block of Keys and Values
        k_ptrs += BLOCK_N * stride_kn
        v_ptrs += BLOCK_N * stride_vk

    class="code-cmt"># Finally, write the accumulated result back to slow HBM memory

    out_ptrs = Out + qvk_offset + offs_out_m[:, None] * stride_om + offs_d[None, :] * stride_on
    tl.store(out_ptrs, acc)
