1. Intuition & Architectural Overview

Imagine you have a highly detailed, high-resolution painting of a landscape. You want to describe it to your friend over the phone so they can paint an exact replica. 1. **The Encoder:** You look at the painting and compress all that visual data into a few key bullet points: *"It's a sunset, there's a red barn on the left, and a river."* You have taken millions of pixels and compressed them into a tiny "bottleneck" of information. 2. **The Decoder:** Your friend hears those bullet points and tries to reconstruct the painting from scratch.

If the reconstruction looks exactly like your original painting, it means your bullet points (the "latent space") successfully captured the true essence of the image.

2. Core Architectural Components

  • It consists of an **Encoder** network that reduces the dimensionality of the input down to a small vector $z$ (the bottleneck or latent space).
  • It consists of a **Decoder** network that takes $z$ and scales it back up to the original input size $\hat{x}$.
  • **Why do this?** If we didn't force a bottleneck, the network would just memorize the input and copy it perfectly. By forcing the data through a tiny bottleneck, the network *must* learn the underlying structure, patterns, and features of the data to reconstruct it. It acts as an incredibly powerful data compression and denoising algorithm.
  • **Term 1 (Expected Log-Likelihood):** The Reconstruction Loss. $q_\phi$ is the Encoder, $p_\theta$ is the Decoder. It measures how well the decoder reconstructs the input given the latent vector.

3. Advantages & Trade-Offs

High representational capacity and parameter efficiency, balanced against inductive bias constraints and hardware memory requirements.

Mathematical Formulation & Equations

The following mathematical equations govern the forward pass, loss calculation, and backward pass dynamics visualised in the animation above:

EQUATION 1
$$ z = \mu + \sigma \odot \epsilon $$
EQUATION 2
$$ \mathcal{L} = - \mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] + D_{KL}(q_\phi(z|x) || p(z)) $$
EQUATION 3
$$ D_{KL} = -\frac{1}{2} \sum_{j=1}^{J} \left( 1 + \log(\sigma_j^2) - \mu_j^2 - \sigma_j^2 \right) $$

05. Variational Autoencoders (VAE)
Deep Dive Implementation

This file demonstrates the explicit architecture of a VAE.
We show the Encoder splitting into Mu and Sigma, the Reparameterization Trick
to allow backpropagation through randomness, and the Decoder reconstructing the image.
We also include the mathematical ELBO Loss function.
"""

import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    """The Variational Autoencoder."""
    class="code-kw">def __init__(self, input_dim=784, hidden_dim=400, latent_dim=20):
        super().__init__()
        
        class="code-cmt"># --- The Encoder (The Master Forger's Eyes) ---
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        
        class="code-cmt"># Instead of outputting one latent vector, the Encoder outputs TWO vectors:
        class="code-cmt"># 1. The Means (Mu)
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        class="code-cmt"># 2. The Log-Variances (LogVar)
        class="code-cmt"># We use LogVar instead of standard deviation because a neural network output 
        class="code-cmt"># can be negative, and standard deviation must be positive. We exponentiate it later.
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        class="code-cmt"># --- The Decoder (The Master Forger's Hands) ---
        self.fc3 = nn.Linear(latent_dim, hidden_dim)
        self.fc4 = nn.Linear(hidden_dim, input_dim)

    class="code-kw">def encode(self, x):
        h1 = F.relu(self.fc1(x))
        return self.fc_mu(h1), self.fc_logvar(h1)

    class="code-kw">def reparameterize(self, mu, logvar):
        """The Reparameterization Trick: z = mu + sigma * epsilon"""
        class="code-cmt"># Convert log variance to standard deviation: sigma = exp(0.5 * log_var)
        std = torch.exp(0.5 * logvar)
        
        class="code-cmt"># Sample pure random noise (epsilon) from a Standard Normal Distribution N(0, 1)
        class="code-cmt"># The noise must be exactly the same shape as the standard deviation tensor.
        eps = torch.randn_like(std)
        
        class="code-cmt"># Calculate z deterministically to allow backpropagation
        z = mu + eps * std
        return z

    class="code-kw">def decode(self, z):
        h3 = F.relu(self.fc3(z))
        class="code-cmt"># Use Sigmoid to push output pixels between 0 and 1
        return torch.sigmoid(self.fc4(h3))

    class="code-kw">def forward(self, x):
        class="code-cmt"># 1. Encode
        mu, logvar = self.encode(x.view(-1, 784))
        class="code-cmt"># 2. Reparameterize (Sample z)
        z = self.reparameterize(mu, logvar)
        class="code-cmt"># 3. Decode
        reconstruction = self.decode(z)
        
        return reconstruction, mu, logvar


class="code-kw">def vae_loss_function(recon_x, x, mu, logvar):
    """
    The ELBO (Evidence Lower Bound) Loss = Reconstruction Loss + Regularization (KL Divergence)
    """
    class="code-cmt"># 1. Reconstruction Loss (Binary Cross Entropy)
    class="code-cmt"># How well did the decoder rebuild the original image?
    class="code-cmt"># reduction='sum' sums the loss across the entire batch
    BCE = F.binary_cross_entropy(recon_x, x.view(-1, 784), reduction=&class="code-cmt">#x27;sum')
    
    class="code-cmt"># 2. KL Divergence (Regularization)
    class="code-cmt"># How close are the mu and logvar distributions to a Standard Normal N(0, 1)?
    class="code-cmt"># Formula: -0.5 * sum(1 + log(sigma^2) - mu^2 - sigma^2)
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    
    class="code-cmt"># Total Loss is the sum
    return BCE + KLD
