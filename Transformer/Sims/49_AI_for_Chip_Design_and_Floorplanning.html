Differentiable Log-Sum-Exp Wirelength

True wirelength min/max operations are non-differentiable. Modern AI chip placers approximate HPWL using smooth Log-Sum-Exp (LSE) functions so PyTorch can backpropagate directly into macro (x, y) coordinates:

LSEx(e) = γ ln ∑ exp(xi/γ) - γ ln ∑ exp(-xi/γ)

Density Overlap Potential Field

If wirelength is optimized alone, all macros collapse onto a single point. To enforce manufacturability, a differentiable density penalty pushes overlapping blocks apart:

Penalty = ∑i ≠ j ReLU( Δxmin - |xi - xj| ) · ReLU( Δymin - |yi - yj| )
