1. Intuition & Architectural Overview

This report details the progression of neural network architectures, explaining how early atomic-scale models evolved into complex structures capable of handling image and sequential data.

* **Mechanism:** Takes inputs, multiplies them by weights, sums them, and passes the result through a step function (acting as an on/off switch). * **Limitation:** It can only solve **linearly separable** problems (e.g., AND/OR logic gates). It famously failed to solve the XOR problem, leading to the "AI Winter." * **Math:** $y = \text{step}(W \cdot X + b)$

2. Core Architectural Components

  • **Mechanism:** Takes inputs, multiplies them by weights, sums them, and passes the result through a step function (acting as an on/off switch).
  • **Limitation:** It can only solve **linearly separable** problems (e.g., AND/OR logic gates). It famously failed to solve the XOR problem, leading to the "AI Winter."
  • **Math:** $y = \text{step}(W \cdot X + b)$
  • **Mechanism:** Information flows in one direction (feedforward). The addition of non-linear activation functions (like Sigmoid or ReLU) allows the network to approximate any continuous mathematical function (Universal Approximation Theorem).

class ExplicitRNN(nn.Module):
    """
    A vanilla RNN built by explicitly defining the weight matrices
    and the hidden state loop, rather than using nn.RNN.
    """
    class="code-kw">def __init__(self, input_size, hidden_size, output_size):
        super(ExplicitRNN, self).__init__()
        self.hidden_size = hidden_size
        
        class="code-cmt"># Input to Hidden Weights
        self.W_xh = nn.Linear(input_size, hidden_size, bias=True)
        class="code-cmt"># Hidden to Hidden Weights (The Memory)
        self.W_hh = nn.Linear(hidden_size, hidden_size, bias=True)
        class="code-cmt"># Hidden to Output Weights
        self.W_ho = nn.Linear(hidden_size, output_size, bias=True)
        
        self.tanh = nn.Tanh()

    class="code-kw">def forward(self, x, h_prev=None):
        """
        x shape: (batch_size, sequence_length, input_size)
        """
        batch_size, seq_length, _ = x.size()
        
        class="code-cmt"># Initialize hidden state to zero if not provided
        if h_prev is None:
            h_prev = torch.zeros(batch_size, self.hidden_size).to(x.device)
            
        outputs = []
        h_current = h_prev
        
        class="code-cmt"># Process the sequence step by step (The limitation of RNNs)
        for t in range(seq_length):
            x_t = x[:, t, :] class="code-cmt"># Get input at time step t
            
            class="code-cmt"># The core RNN equation: h_t = tanh(W_xh * x_t + W_hh * h_{t-1} + b)
            h_current = self.tanh(self.W_xh(x_t) + self.W_hh(h_current))
            
            class="code-cmt"># Compute output for this step
            o_t = self.W_ho(h_current)
            outputs.append(o_t.unsqueeze(1))
            
        class="code-cmt"># Concatenate outputs across the sequence dimension
        outputs = torch.cat(outputs, dim=1)
        return outputs, h_current
